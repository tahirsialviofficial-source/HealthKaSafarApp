# Health Ka Safar Android App

Android WebView app for https://healthkasafar.blogspot.com/

## Version
- Version: 1.1
- Version code: 2
- Package: `com.healthkasafar.app`
- Min SDK: 23
- Target/Compile SDK: 35
- Java: 17

## Invoice compatibility update
This version adds Android-side handling for HTML downloads and common `blob:` / `data:` download links used by browser invoice tools. Invoice files generated by the Blogger page can be saved to the Android Downloads folder when the page exposes them through a download link. The normal Android share intent is also available to native integrations.

## Build
Use GitHub Actions: open **Actions** → **Build Health Ka Safar APK** → **Run workflow**. The resulting `app-debug.apk` is in the artifact `HealthKaSafar-debug-apk`.
